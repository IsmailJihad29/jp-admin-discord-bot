১. সিস্টেম ওভারভিউ ও বটের পরিচয় (SYSTEM OVERVIEW)
================================================================================
JP ADMIN হলো EJP Mentorship & Career Accelerator প্রোগ্রামের জন্য তৈরি একটি
পূর্ণাঙ্গ স্বয়ংক্রিয় ডিসকর্ড অ্যাসিস্ট্যান্ট এবং ডেটাবেজ ম্যানেজমেন্ট সিস্টেম।

প্রধান সুবিধাসমূহ:
• গুগল শিট ডেটাবেজ ব্যাকএন্ড (১০টি কোর ট্যাব): কোনো পেইড ডেটাবেজ ছাড়াই সম্পূর্ণ রিলায়েবল ডেটা ট্র্যাকিং।
• ওয়ান-টাইম জব ট্র্যাকার লিংক: শিক্ষার্থী একবার শিট লিংক করলে প্রতি রাত ১১:৩০ এ স্বয়ংক্রিয়ভাবে স্ক্র্যাপ করে পয়েন্ট হিসাব।
• এআই ইন্টারভিউ প্রিপারেশন: শিক্ষার্থী ইন্টারভিউ পোস্ট করলেই জেমিনি এআই তাৎক্ষণিকভাবে ৩০টি কাস্টম ইন্টারভিউ প্রশ্ন ও গাইড দেয় এবং পয়েন্ট যোগ করে।
• কোডিং টাস্ক লাইফসাইকেল: কোম্পানি অ্যাসাইনমেন্ট অ্যানাউন্সমেন্ট (+১ pt), সাবমিশন (+১ pt) এবং ওভারডিউ পেনাল্টি (-২ pts)।
• স্বয়ংক্রিয় অ্যাটেন্ডেন্স ও ওয়ার্নিং: গুগল ফর্ম স্ক্যান করে পয়েন্ট আপডেট এবং সপ্তাহে ৩ দিন অনুপস্থিত থাকলে স্বয়ংক্রিয় ওয়ার্নিং।
• সাপ্তাহিক লিডারবোর্ড: প্রতি বৃহস্পতিবার সন্ধ্যা ৬:০০ টায় ৭ দিনের সমন্বিত পারফরম্যান্স লিডারবোর্ড প্রকাশ।
• স্মার্ট এআই কুয়েরি ও নাডজ: সাধারণ ভাষায় প্রশ্ন করে শিটের ডেটা বিশ্লেষণ এবং এক ক্লিকে শিক্ষার্থীদের রিমাইন্ডার পাঠানো।

২. সম্পূর্ণ সেটআপ ও বট ইনভাইট গাইড (STEP-BY-STEP SETUP GUIDE)
================================================================================

--------------------------------------------------------------------------------
ধাপ ১: গুগল শিট ও Apps Script ব্যাকএন্ড সেটআপ
--------------------------------------------------------------------------------
• ১. গুগল ড্রাইভে গিয়ে একটি নতুন Google Spreadsheet তৈরি করুন এবং ফাইলের নাম দিন (যেমন: "EJP Cohort Database")।
• ২. মেন্যু বার থেকে Extensions > Apps Script-এ যান।
• ৩. সেখানে থাকা ডিফল্ট কোড মুছে ফেলে আপনার প্রোজেক্টের google-apps-script/Code.gs ফাইলের সম্পূর্ণ কোড পেস্ট করুন।
• ৪. ফাইলের শুরুর দিকে CONFIG.SECRET_KEY যাচাই করুন (ডিফল্ট: "JP_ADMIN_26")।
• ৫. উপরে ডান পাশে Deploy > New deployment সিলেক্ট করুন:
     - Select type (গিয়ার আইকন): Web app
     - Description: JP Admin Backend v50
     - Execute as: Me (আপনার গুগল অ্যাকাউন্ট)
     - Who has access: Anyone (খুবই গুরুত্বপূর্ণ, অন্যথায় বট শিটে কানেক্ট হতে পারবে না)
• ৬. Deploy বাটনে ক্লিক করে তৈরি হওয়া Web App URL (.../exec) কপি করে নিরাপদে সংরক্ষণ করুন।

--------------------------------------------------------------------------------
ধাপ ২: Discord Developer Portal ও বট তৈরি
--------------------------------------------------------------------------------
• ১. Discord Developer Portal (https://discord.com/developers/applications) এ লগইন করুন।
• ২. New Application বাটনে ক্লিক করে বটের নাম দিন (যেমন: "JP ADMIN")।
• ৩. বাম পাশের মেন্যু থেকে Bot ট্যাবে যান:
     - Privileged Gateway Intents সেকশনে যান।
     - নিচের ৩টি অপশনই Enable (ON) করে দিন:
       1. PRESENCE INTENT
       2. SERVER MEMBERS INTENT
       3. MESSAGE CONTENT INTENT
     - Reset Token-এ ক্লিক করে Bot Token টি কপি করে সেভ করুন।
• ৪. বাম পাশের OAuth2 > General ট্যাবে গিয়ে Client ID টি কপি করুন।

--------------------------------------------------------------------------------
ধাপ ৩: বট সার্ভারে ইনভাইট করা
--------------------------------------------------------------------------------
• ১. সরাসরি নিচের লিংকের YOUR_CLIENT_ID এর জায়গায় আপনার Client ID বসিয়ে ব্রাউজারে ওপেন করুন:
     https://discord.com/api/oauth2/authorize?client_id=YOUR_CLIENT_ID&permissions=8&scope=bot
• ২. আপনার সার্ভার নির্বাচন করে Authorize বাটনে ক্লিক করুন (Administrator পারমিশন সহ)।

--------------------------------------------------------------------------------
ধাপ ৪: প্রোজেক্ট কনফিগারেশন (.env) ও রান করা
--------------------------------------------------------------------------------
• ১. প্রোজেক্ট ফোল্ডারে একটি .env ফাইল তৈরি করুন এবং নিচের মানগুলো বসান:
     DISCORD_TOKEN=আপনার_বট_টোকেন
     CLIENT_ID=আপনার_ক্লায়েন্ট_আইডি
     GEMINI_API_KEY=আপনার_গুগল_জেমিনি_এপিআই_কি
     DEFAULT_GAS_URL=আপনার_গুগল_অ্যাপস_স্ক্রিপ্ট_ওয়েব_অ্যাপ_ইউআরএল
     DEFAULT_GAS_SECRET=JP_ADMIN_26
     DEFAULT_TIMEZONE=Asia/Dhaka
     PORT=3000

• ২. ডিপেন্ডেন্সি ইনস্টল ও বট রান করুন:
     npm install
     npm start

--------------------------------------------------------------------------------
ধাপ ৫: সার্ভারে ফার্স্ট-টাইম ইনিশিয়ালাইজেশন (কমান্ড রান)
--------------------------------------------------------------------------------
বট সার্ভারে অনলাইন হওয়ার পর সুপারভাইজার #jp-admin চ্যানেলে নিচের কমান্ডগুলো ক্রমানুসারে রান করবেন:

• ১. সার্ভার চ্যানেল ও রোল তৈরি:
     !setupserver
     (বট স্বয়ংক্রিয়ভাবে ক্যাটাগরি, রোল এবং ৯টি অফিশিয়াল চ্যানেল পারমিশন সহ তৈরি করবে)

• ২. গুগল শিট কানেক্ট ও কোর ১০টি ট্যাব তৈরি:
     !setgas https://script.google.com/macros/s/YOUR_DEPLOYMENT_ID/exec
     !setupcohortsheet fresh confirm https://docs.google.com/spreadsheets/d/YOUR_SHEET_ID/edit

• ৩. সিস্টেম সংযোগ ও ডায়াগনস্টিক টেস্ট:
     !doctor

• ৪. সার্ভারের মেম্বারদের শিটের সাথে সিঙ্ক করা:
     !syncmembers

• ৫. চ্যানেলগুলোতে প্রয়োজনীয় গাইডলাইন ও বাটন পোস্ট করা:
     !posttemplates all

৩. গুগল শিট ডেটাবেজ স্ট্রাকচার (১০টি কোর ট্যাব)
================================================================================

১. All Data
• ভূমিকা: শিক্ষার্থীদের মূল মাস্টার প্রোফাইল।
• কলামসমূহ: Name, Your Course Email Address, Mobile Number, Discord Username, Region, Subregion, Notes.
• প্রদানকারী: অ্যাডমিন / মেন্টর।

২. Bot_Map
• ভূমিকা: ডিসকর্ড মেম্বারদের সাথে ডেটাবেজের রিয়েল-টাইম আইডি ম্যাপিং।
• কলামসমূহ: Email, Name, Discord Username, Discord ID, Status, Region, Subregion, Phone, Match Source, Review Note.
• প্রদানকারী: বট (!syncmembers কমান্ডের মাধ্যমে)।

৩. Attendance
• ভূমিকা: শিক্ষার্থীদের দৈনিক উপস্থিতির ঐতিহাসিক ম্যাট্রিক্স।
• কলামসমূহ: Name, Email, Phone, Discord ID, Status, Remarks এবং পরবর্তী কলামগুলোতে তারিখভিত্তিক P (উপস্থিত), A (অনুপস্থিত), L (অনুমোদিত ছুটি)।
• প্রদানকারী: Apps Script ও বট।

৪. Daily Attendance
• ভূমিকা: শিক্ষার্থীদের মূল গুগল ফর্ম রেসপন্স ট্যাব।
• কলামসমূহ: Timestamp, Email Address, Full Name, Discord ID, Attendance Status.
• প্রদানকারী: Google Forms।

৫. Morning Attendance
• ভূমিকা: সকালের স্পেশাল সেশনের গুগল ফর্ম রেসপন্স ট্যাব।
• কলামসমূহ: Timestamp, Email Address, Full Name, Discord ID, Attendance Status.
• প্রদানকারী: Google Forms।

৬. Leave_Requests
• ভূমিকা: শিক্ষার্থীদের জমা দেওয়া ছুটির আবেদন ও মেন্টরদের সিদ্ধান্ত লগ।
• কলামসমূহ: Request ID, Timestamp, Discord ID, Name, Email, Start Date, End Date, Reason, Status, Mentor Note.
• প্রদানকারী: বট (#leave-request চ্যানেল থেকে)।

৭. Job_Sheets
• ভূমিকা: শিক্ষার্থীদের পার্সোনাল জব ট্র্যাকার গুগল শিট লিংক ও শিট আইডি রেজিস্ট্রি।
• কলামসমূহ: Discord ID, Name, Email, Sheet URL, Sheet ID, Tab GID, Status, Last Scraped.
• প্রদানকারী: বট (#job-tracker চ্যানেল থেকে)।

৮. Jobs_Daily
• ভূমিকা: প্রতিদিন রাত ১১:৩০ এ স্ক্র্যাপ করা দৈনিক আবেদন সংখ্যা ও পয়েন্টের হিসাব।
• কলামসমূহ: Date, Email, Count, Name, Discord ID, Total Rows, New Rows, Points.
• প্রদানকারী: বট অটো-স্ক্র্যাপার।

৯. Interview_Log
• ভূমিকা: শিক্ষার্থীদের সকল ইন্টারভিউয়ের ইতিহাস ও বিবরণ।
• কলামসমূহ: Logged Date, Name, Discord ID, Company, Serial, Interview Date, Role Details, Discord Link, Timestamp.
• প্রদানকারী: বট (#interview-preparation চ্যানেল থেকে)।

১০. Job_Tasks
• ভূমিকা: বিভিন্ন কোম্পানির কোডিং অ্যাসাইনমেন্ট ট্র্যাকিং ও রিভিউ লেজার।
• কলামসমূহ: Task ID, Timestamp, Discord ID, Student Name, Company, Role, Tech Stack, Deadline, Submission Status, GitHub Link, Task Link, Description Link, Submitted At, Mentor Status, Mentor Note, Points Awarded.
• প্রদানকারী: বট (#jobs-task-updates চ্যানেল থেকে)।

১১. Holidays (অতিরিক্ত)
• ভূমিকা: অফডে ও সরকারি ছুটির ক্যালেন্ডার।
• কলামসমূহ: Start Date, End Date, Holiday Title, Logged By, Created At.

৪. শিক্ষার্থী এন্ড: ফিচার ও ব্যবহারের নিয়ম (STUDENT WORKFLOW)

১. জব ট্র্যাকার শিট লিংক করা (One-time Setup):
• চ্যানেল: #job-tracker
• নিয়ম:
  - শিক্ষার্থী তার পার্সোনাল গুগল শিটের Share সেটিংসে গিয়ে "Anyone with the link can view" সিলেক্ট করবে।
  - তারপর চ্যানেলে শিটের লিংক পেস্ট করবে অথবা কমান্ড লিখবে:
    !linksheet <গুগল_শিট_ইউআরএল>
    উদাহরণ: !linksheet https://docs.google.com/spreadsheets/d/12345/edit
  - বট সাথে সাথে শিটটি ভেরিফাই করে রেজিস্টার করে নেবে।
  - প্রতিদিন রাতে (১১:৩০ PM) বট অটোমেটিক শিট রিড করে পয়েন্ট যোগ করবে। প্রতিদিন নতুন করে লিংক দেওয়ার দরকার নেই।
